# JavaScript Decision Making - 

## Overview
This exercise is designed to help you practice JavaScript conditional statements, comparison operators, and arithmetic operators.

## Getting Started

1. Open `index.html` in your web browser
2. Open the browser's Developer Console (F12 or right-click > Inspect > Console)
3. Open `public/script/script.js` in your code editor
4. Follow the directions in the script file and complete the exercises

## What You'll Practice

### Part 1: Syntax Practice
- **Comparison Operators**: Practice using `>`, `<`, `>=`, `<=`, `==`, `===`, `!=`, `!==`
- **Conditional Statements**: Write `if`, `if/else`, and `if/else if/else` statements
- **Arithmetic Operators**: Work with `+`, `-`, `*`, `/`, `%`, `**`, `++`, `--`
- **Type Conversion**: Understand how JavaScript handles different data types

### Part 2: Temperature Conversion App
Build a simple app that:
- Prompts the user for a temperature in Fahrenheit
- Converts it to Celsius
- Displays the result on the webpage
- Shows a message based on the temperature

## Instructions

### For Practice (script.js)
You can practice in the **`public/script/script.js`** file. Follow the numbered questions and directions provided in the comments.

Test your code frequently by:
- Checking the browser console for output
- Refreshing the page to see changes
- Using `console.log()` to debug

### For Autograding (solutions.js)
Complete the functions in **`public/script/solutions.js`** for GitHub Classroom autograding.

Each function has TODO comments explaining what you need to implement. DO NOT change the function names or parameters.

To run tests locally:
```bash
npm install
npm test
```

The tests are worth 100 points total:
- Part 1.A: Comparison Operators (15 points)
- Part 1.B: Conditional Statements (25 points)
- Part 1.C: Arithmetic Operators (20 points)
- Part 2: Temperature Conversion (40 points)

## Tips

- Read each question carefully
- Test your code after completing each question
- Use the example provided as a guide
- Don't forget to check the console for errors
- For the Temperature Conversion App, plan your steps with pseudocode first

Good luck and happy coding!
